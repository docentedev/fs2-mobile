# Documentación de Disco

| Documento | Para qué sirve |
|---|---|
| [REQUERIMIENTOS.md](REQUERIMIENTOS.md) | Guía funcional y técnica adaptable: el caso, el núcleo que debe conservarse, decisiones libres, reglas de negocio, modelo de datos de referencia, pantallas y criterios de aceptación. Incluye el protocolo de compilación temprana, plan con checklist y CHANGELOG. |
| [ARQUITECTURA.md](ARQUITECTURA.md) | Explicación de la implementación real: capas, estructura de directorios, navegación, persistencia y justificación de los tipos de Kotlin usados. |
| [../CHANGELOG.md](../CHANGELOG.md) | Registro de cambios y plan con checklist por iteración. |

## Orden de lectura sugerido

1. **REQUERIMIENTOS.md** para entender el producto y su alcance.
2. **ARQUITECTURA.md** para entender cómo está construido (capas, navegación,
   persistencia, capa remota/autenticación y tutoriales de extensión).
